# Proyecto de práctica de GitHub

Este repositorio se usa para practicar flujos colaborativos de GitHub:

- Issues
- Pull Requests
- Code Review
- Comentarios
- Asignaciones

## Contenido

- `index.html`: Página web de ejemplo.

## Cómo contribuir

1. Crea una rama desde `main`.
2. Realiza tus cambios.
3. Abre un Pull Request.
4. Solicita revisión a otro usuario.
